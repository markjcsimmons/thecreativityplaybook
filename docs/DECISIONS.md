- **Temporary site password (2026-11-03, Mark).** `middleware.ts` (Vercel Routing Middleware) asks for a password before showing any page. It is off unless `SITE_PASSWORD` is set. `ALLOWED_IPS` (comma-separated) skips the password for Mark's own network. The password and IPs live only in Vercel environment variables, never in the repo. The cookie `cp_gate` holds a keyed hash, not the password. A four-digit password can be guessed, so this keeps casual visitors out; it is not real security. To open the site: delete `SITE_PASSWORD` in Vercel (Production) and redeploy, then delete `middleware.ts` and `@vercel/functions` when the gate is no longer needed. While the gate is on, people who enter the password get one cookie, so the privacy page's "no cookies" line applies once the gate is removed.
